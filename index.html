      Acerca de Viaja en Bici

      MVP de rutas ciclistas para Bogotá. Compara tres perfiles, muestra ciclorrutas oficiales y permite calcular rutas en el dispositivo sin conexión.

      Fuentes principales

      • Valhalla (servidor público FOSSGIS) para ruteo y giro a giro.
      • BRouter como motor alternativo de comparación.
      • API de Ruteo de Mapas Bogotá (Catastro Distrital) para alternativas locales.
      • IDU / Catastro Bogotá para la capa oficial de ciclorrutas.
      • OpenStreetMap (© colaboradores, ODbL) para el grafo y mapa base offline.
      • Nominatim para búsqueda de direcciones, con uso moderado.

      Los servicios públicos son de demostración. Para producción conviene autohospedar los motores y revisar las licencias y políticas de uso de cada fuente. Versión .
